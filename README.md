🛡️ GOLIATH SECURITY PROTOCOL

Herramienta de supervisión y auditoría básica de seguridad web.

GOLIATH es un proyecto desarrollado en Python que reúne diferentes módulos para supervisar y revisar aspectos básicos de seguridad de servidores web.

Características

- Apache Monitor: supervisión de Apache.
- File Scanner: exploración de archivos.
- Firewall Check: revisión de encabezados de seguridad HTTP.
- Security Audit: auditoría básica del portal.

Sistemas compatibles

- Windows 10 y 11.
- Kali Linux.
- Debian.
- Ubuntu.

Instalación en Linux

GOLIATH cuenta con un instalador automático para distribuciones basadas en Debian.

1. Instalar curl

Abre una terminal y ejecuta:

sudo apt update
sudo apt install curl -y

2. Instalar GOLIATH

Ejecuta el siguiente comando:

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/Rudeboy4412/GOLIATH-Security-Protocol/main/install.sh)"

El instalador se encargará de:

1. Instalar las dependencias necesarias.
2. Descargar el código fuente.
3. Preparar el entorno de Python.
4. Instalar las dependencias del proyecto.
5. Configurar el comando de ejecución.

3. Ejecutar GOLIATH

Una vez terminada la instalación:

goliath

Instalación en Windows

Descarga el ejecutable disponible en las publicaciones del proyecto y ejecútalo.

Aviso de seguridad

GOLIATH es una herramienta en desarrollo. Sus resultados son orientativos y no garantizan la detección de todas las vulnerabilidades.

Utiliza sus funciones únicamente en sistemas propios o para los que tengas autorización.
